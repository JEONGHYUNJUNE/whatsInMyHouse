개인정보·기록 저장 안내

게임을 플레이하거나 기록을 등록하기 전에 어떤 정보가 저장되고 공개되는지 확인해 주세요.

게임에서 입력받는 정보

회원가입 없이 플레이할 수 있으며, 게임에서 실명·전화번호·이메일을 입력받지 않습니다. 탈출 후 순위 등록을 선택하면 닉네임을 입력합니다. 닉네임에는 실명이나 연락처 대신 공개해도 괜찮은 별명을 사용해 주세요.

서버에 저장하는 도전과 기록

도전 시작 시 임의의 도전 식별값과 시작 시각을 만들고, 탈출 시 완료 시각과 탈출 시간을 확정합니다. 순위 등록을 누르면 해당 기록에 닉네임과 등록 시각이 연결됩니다. 닉네임과 탈출 시간은 전체 랭킹에 공개되며 두 게임 주소에서 같은 랭킹을 사용합니다.

  • 같은 닉네임의 최고기록 중 전체 상위 20개만 순위표에 보관합니다.
  • 순위 밖 기록과 중복된 느린 기록은 등록 처리 시 정리합니다.
  • 진행 중인 도전은 보존합니다. 시작 후 45분이 지난 미등록 기록은 이후 새 도전·등록 시 정리합니다.
  • 등록 재시도가 중복되지 않도록 결과 응답을 45분간 임시 보관하며, 만료 후 새 도전·등록 시 정리합니다.

이 브라우저에 저장하는 정보

‘내 최단 기록’과 마지막으로 사용한 닉네임은 브라우저의 로컬 저장소에 저장합니다. 다른 기기나 브라우저와 자동으로 동기화되지 않습니다. 브라우저 설정에서 이 사이트의 데이터를 삭제하면 해당 기기의 저장값도 삭제됩니다. 로컬 저장값을 삭제해도 이미 등록된 서버 순위 기록이 함께 삭제되지는 않습니다.

서비스 제공업체

웹사이트 제공에는 Vercel, 도전·순위 데이터 저장에는 Supabase를 이용합니다. 제공업체의 서비스 운영과 보안 관련 처리는 각 업체의 안내도 참고해 주세요.

Vercel 개인정보 안내 · Supabase 개인정보 안내

광고와 외부 추적

현재 이 사이트에는 광고를 표시하거나 광고용 스크립트를 실행하지 않습니다. 광고 서비스가 실제로 연결되는 경우에는 관련 처리와 이용자 선택 사항을 이 안내에 반영한 뒤 적용합니다.

기록 등록은 선택입니다

닉네임을 등록하지 않아도 탈출 결과를 확인하고 다시 플레이할 수 있습니다. 공개된 순위표에는 닉네임과 탈출 시간만 표시하며 도전 식별값은 표시하지 않습니다.
